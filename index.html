What the tool establishes

Field, role, template line and candidate marker attribution without model weights. Dynamic token witnesses establish an input structure the deployment can reproduce.

What remains open

Production specificity, held-out generalization, downstream safety and practical value over competent direct rendering. A warning is a candidate; its absence is not a security certificate.
